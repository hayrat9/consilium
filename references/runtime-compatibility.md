# Claude и Codex

Один SKILL.md с общим Agent Skills frontmatter: name и description. Специальные
поля выбора модели, hooks, разрешения shell и серверы MCP не добавляются.
agents/openai.yaml — необязательные метаданные интерфейса Codex; протокол находится
в SKILL.md и references, поэтому не зависит от чтения этого YAML другой средой.

Claude Code: `/consilium <задача>`; Codex CLI/IDE: `$consilium <задача>`.
В другой среде с поддержкой Agent Skills выбрать установленный навык в её интерфейсе.
Хештег #council распознаётся как текстовая просьба, если описание навыка доступно
агенту; отдельный Telegram-бот или обработчик тегов в пакет не входит.

Сначала проверить доступные поисковые инструменты, сохранение файлов, исполнение
Python и делегирование. Подагентов использовать только если это разрешено средой
и текущим поручением; не выдумывать вызовы Claude Task, Agent или spawn_agent.
В последовательном режиме открыто указать, что перспективы разыгрывает один
исполнитель и их независимость ограничена. Утверждённый состав сохранить целиком.
Не менять выбранную модель или провайдера автоматически. Необязательный
multi_model требует явного выбора пользователя и реально доступных каналов по
[правилам исполнения](execution-modes.md); сетевой оркестратор в пакет не входит.

В полной глубине для последних 30 дней использовать доступный last30days либо явно обозначенный
публичный поиск с проверкой дат и первоисточников. Без сети или при ошибках сохранить
пробелы; возможен ограниченный разбор доступных материалов, если не скрывать его
ограничения. Не имитировать свежие сведения и не выдавать его за полный свежий срез.

Python 3.10+ нужен только для необязательных локальных помощников. Если исполнения
кода нет, протокол можно выполнить вручную; расчёты проверить доступным способом.
Вызовы scripts/... выполнять относительно папки установленного навыка. Рабочие
сессии и материалы пользователя сохранять отдельно от библиотеки и репозитория.

Совместимость формата проверяется локально; это не означает испытание на всех
версиях Claude/Codex или доступность их инструментов и тарифов.
