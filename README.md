# Консилиум · Consilium

**Междисциплинарный AI-совет для Claude Code и Codex.** Помогает придумать решения,
сравнить варианты и разобраться в сложном вопросе с разных профессиональных сторон.
Рабочий язык — русский; язык результата можно задать в запросе.

Например: выбрать стратегию продукта, найти идеи для обучения, оценить архитектуру
приложения, разобрать исследовательский вопрос или проверить предложение перед запуском.
Подходит разным темам; набор дисциплин каждый раз определяется задачей.

## Как работает

1. Ведущий уточняет цель, предлагает полезные дисциплины, их вопросы, формат и оценку ресурсов.
2. **Вы утверждаете состав.** До этого именные роли и раунды не запускаются.
3. Агент подбирает AI-перспективы по профильным работам и проверяет свежие источники
   за последние 30 дней. Пробелы и недоступные источники отмечает явно.
4. Три раунда: независимые позиции или идеи → критика и развитие → проверка вывода.
5. Вы получаете варианты, основания, ключевые разногласия, ограничения и план проверки.

Режим выбирается по задаче. **Экспертный разбор** оценивает имеющиеся варианты.
**Брейншторм** сначала генерирует идеи без ранних баллов, затем развивает и проверяет их.
Состав не закреплён за списком знаменитостей и не ограничен девятью ролями:
большой совет можно выполнить волнами.

Участники — **AI-симуляции профессиональных подходов**, а не приглашённые специалисты.
Их согласие не доказывает истинность, а баллы не являются вероятностью успеха.
Источники, возражения и неопределённость важнее известности имени.

## Установка

Скачайте репозиторий через **Code → Download ZIP**, распакуйте его и откройте терминал
в папке, содержащей `SKILL.md`. Одинаковый пакет устанавливается в обе среды.
Для команд ниже нужен Python 3.10+; на Windows вместо `python3` можно использовать `py -3`.

### Claude Code

```bash
python3 scripts/install.py --platform claude
```

Установит в `~/.claude/skills/consilium/`. Вызов:

```text
/consilium Придумай новые форматы обучения для небольшого онлайн-курса.
```

### Codex CLI / IDE

```bash
python3 scripts/install.py --platform codex
```

Установит в `~/.agents/skills/consilium/`. Вызов:

```text
$consilium Сравни три варианта архитектуры приложения с учётом поддержки и бюджета.
```

Если навык не появился, перезапустите сессию. В интерфейсах с выбором навыков можно
выбрать «Консилиум» из списка. Это локальная установка; доступность навыков в облачных
сессиях зависит от продукта и его настроек.

### Только для одного проекта

```bash
python3 scripts/install.py --platform claude --project /path/to/project
python3 scripts/install.py --platform codex --project /path/to/project
```

Пути: `.claude/skills/consilium/` или `.agents/skills/consilium/` внутри выбранного проекта.
Установщик не использует сеть, не меняет настройки модели и отказывается заменять
существующую папку. Перед обновлением сохраните прежнюю версию и сами выберите новый
каталог. Для просмотра назначения без записи добавьте `--dry-run`.

Без Python можно вручную скопировать папку пакета в один из указанных каталогов под
именем `consilium`, сохранив `SKILL.md`, `references/`, `assets/`, `scripts/` и `agents/`.

## Примеры запросов

```text
Используй Консилиум. Нужно выбрать подход к запуску образовательного проекта.
Сначала предложи дисциплины и объясни вклад каждой.

Используй Консилиум в режиме брейншторма: придумай способы уменьшить количество
ошибок при передаче задач между командами. Ограничение — без покупки новых сервисов.

Используй Консилиум для разбора этих двух гипотез. Покажи сильнейшие возражения
и какой эксперимент поможет их различить.
```

`#council` можно использовать как текстовый псевдоним, когда навык доступен агенту.
Сам хештег не устанавливает навык и не регистрирует команду в Telegram или другом чате.

## Что требуется и что входит

- Среда, которая читает Agent Skills. Код и протокол не привязаны к одному провайдеру.
- Доступный поиск для свежих источников. [last30days](https://github.com/mvanhorn/last30days-skill)
  необязателен: без него используется явно обозначенный публичный поиск.
- Подагенты необязательны. При последовательном выполнении агент отмечает ограниченную
  независимость симуляций. Модель автоматически не меняется.
- Python-помощники работают без сети и внешних библиотек: проверка структуры сессии,
  расчёт сценарной сметы и сравнение вариантов по критериям.

```bash
python3 -B scripts/self_test.py
python3 scripts/session_check.py assets/session.template.json
python3 scripts/estimate_resources.py assets/estimate.example.json
```

Шаблон намеренно начинается до утверждения состава. Пример сметы содержит учебные
числа и не показывает стоимость реальной сессии. Валидатор проверяет структуру,
но не подлинность согласования, истинность источников или качество идей.

Использование модели и инструментов зависит от вашего тарифа. Навык не выдаёт доступ
к чужим аккаунтам, не устанавливает платные API и не публикует результаты без поручения.
Сохраняйте пользовательские сессии отдельно от репозитория навыка.

[OpenAI — Build skills](https://learn.chatgpt.com/docs/build-skills).

продуктов, облачных окружений или каждого будущего ответа модели.
